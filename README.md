#Estructura de Datos — Unidad 2: Algortimos

Proyecto académico desarrollado para comprender, implementar y analizar la eficiencia de los principales algoritmos de **recursividad, ordenamiento y búsqueda**, utilizando **Python** y **Java** como lenguajes base.

---

##Descripción del Proyecto

Este proyecto recopila ejercicios, ejemplos y demostraciones prácticas de los algoritmos más importantes de la **Unidad 2** en la materia **Estructura de Datos**, impartida por el profesor **César Ricardo Alducin Ruiz**.

Los temas principales incluyen:

- **2.1 Recursividad**
  - Factorial  
  - Fibonacci  
  - Torres de Hanói  

- **2.2 Ordenamiento**
  - Burbuja (Bubble Sort)  
  - Inserción (Insertion Sort)  
  - Selección (Selection Sort)  
  - Mezcla (Merge Sort)  
  - QuickSort  

- **2.3 Búsqueda**
  - Secuencial (Lineal)  
  - Binaria  

---

##Objetivos

- Comprender la **lógica teórica** de los algoritmos y su complejidad **O(n)**.  
- Desarrollar la **capacidad de implementación** en **Python y Java**.  
- Relacionar el conocimiento con su **uso profesional** en **Inteligencia Artificial y Machine Learning**.  

---

##Requisitos Previos

- Python 3.10 o superior  
- Java JDK 17 o superior  
- Editor de código (VS Code, IntelliJ, PyCharm, etc.)  
- Conocimientos básicos de:
  - Estructuras de datos lineales
  - Programación modular
  - Notación Big-O
